Google Docs vs. HTML

Google Docs and HTML can both be used to write text, but they work in very different ways.

What You See vs. What You Write

Google Docs shows you the finished page as you type. To make a heading, you pick it from a menu. In HTML, you write tags like <h1> and <p>, and you only see the finished page when you open the file in a browser.

Formatting

In Google Docs, you change fonts and colours with buttons on the toolbar. In HTML, the tags describe what the content is, and the look is set separately with CSS. This keeps content and presentation apart.

Where It's Used

Google Docs is made for documents that people share, edit together, and print. HTML is made for web pages that open in any browser on any device.

Collaboration

Google Docs lets several people edit at once and leave comments. HTML files are usually edited by one person at a time in a code editor.
