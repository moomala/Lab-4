From Type to Web

Before computers, printers built pages by hand using small metal letters arranged in a frame, which was slow but gave them full control over every page. Desktop publishing moved this work onto the computer, letting designers place text and images on screen and make edits in seconds instead of hours, though the goal was still a fixed page, usually for print. HTML and CSS are made for the web instead: HTML describes what the content is, CSS controls how it looks, and the page adjusts to fit any screen. All three arrange text so it's easy to read, but typesetting and desktop publishing create fixed layouts where the designer decides exactly where everything goes, while HTML and CSS separate content from presentation and let the browser decide the final layout.
